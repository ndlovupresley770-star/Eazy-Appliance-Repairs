Smeg Appliance Error Code & Fault Diagnostic Guide

Is your Smeg dishwasher, washing machine, or refrigerator displaying an error code or experiencing a malfunction? Use our instant lookup tool to identify the issue and recommended technician fix.

Appliance Error / Code Diagnosed Issue Recommended Technician Fix Action
Dishwasher E1 Aquastop Anti-Flood Base Pan Leak Trip Inspect base pan for moisture, test anti-flood float switch, replace leaking internal hose clamp or inlet valve. Book Fix
Dishwasher E2 Water Supply Inlet Timeout Clean water supply mesh filter, check home water pressure, replace restricted Aquastop solenoid valve. Book Fix
Dishwasher E3 Wash Water Heating Fault / NTC Sensor Test continuity of flow-through heater element, replace failed NTC temperature sensor, reset control board. Book Fix
Dishwasher E5 Water Drainage Timeout / Blocked Pump Clear food debris filter trap, check drain hose routing, replace obstructed synchronous drain pump motor. Book Fix
Washer E1 Water Inlet Timeout / Low Supply Pressure Clean inlet valve filters, check household water supply taps, replace inlet water valve assembly. Book Fix
Washer E2 Drainage Obstruction / Pump Timeout Clear lint filter trap, inspect drain hose for kinks, replace burned drain pump motor. Book Fix
Washer E4 Electronic Door Interlock Latch Failure Inspect door strike alignment, test electronic door interlock switch, replace locking solenoid. Book Fix
Fridge E0 / E4 NTC Temperature Sensor or Defrost Fault Test thermistor resistance, replace burned defrost heating element, calibrate inverter control board. Book Fix
Dryer No Heat Tripped High-Limit Thermal Safety Fuse Clean lint filter ducting thoroughly, replace tripped thermal safety cut-out fuse and heating coil. Book Fix

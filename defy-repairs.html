Defy Appliance Error Code & Fault Diagnostic Guide

Is your Defy washing machine, fridge, or oven flashing an error code or experiencing a breakdown? Use our instant lookup tool to identify the issue and recommended technician fix.

Appliance Error / Code Diagnosed Issue Recommended Technician Fix Action
Washer E1 Water Inlet Timeout / Low Supply Pressure Clean inlet valve mesh filters, check home water tap pressure, replace water inlet solenoid valve. Book Fix
Washer E2 Drainage Obstruction / Pump Timeout Clear coin trap filter debris, inspect drain hose for kinks, replace worn drain pump motor. Book Fix
Washer E3 Unbalanced Wash Load Detected Rearrange wash load, check outer tub suspension springs, test out-of-balance sensor switch. Book Fix
Washer E4 Door Interlock Latch Failure Inspect door strike alignment, test electronic door lock solenoid, replace latch unit. Book Fix
Fridge E0 / E4 NTC Temperature Sensor or Defrost Fault Test thermistor resistance, replace burned defrost heating element, reset PCB control board. Book Fix
Fridge Clicking Compressor PTC Relay / Overload Tripped Test compressor winding resistance, replace burned starter relay with surge-resistant unit. Book Fix
Oven Tripping Earth Leakage Fault in Bake/Fan Element Test element insulation resistance with multimeter, replace shorted circular Thermofan element. Book Fix
Oven No Heat Blown Element or Selector Switch Failure Test function selector switch contacts, swap burned bake or Thermofan heating element. Book Fix
Dryer No Heat Tripped High-Limit Thermal Cut-Out Fuse Clean lint filter ducting completely, replace tripped thermal fuse and heating coil. Book Fix

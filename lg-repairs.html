LG Appliance Error Code Diagnostic Guide

Is your LG appliance displaying a fault code on its digital panel? Use our instant lookup tool to identify the cause and recommended technician fix.

Appliance Error Code Diagnosed Issue Recommended Technician Fix Action
Washer OE Drainage Failure (Water Not Emptying) Inspect drain filter trap, test drain hose for blockage, replace failed drain pump. Book Fix
Washer LE Motor Locked / Hall Sensor Error Test Direct Drive motor assembly, replace burned hall sensor or wiring harness. Book Fix
Washer UE Unbalanced Load Error Rebalance laundry load, level unit feet, test drum suspension dampers. Book Fix
Washer dE / dE1 Door Lock Switch Malfunction Inspect door latch alignment, replace faulty electronic door interlock switch. Book Fix
Fridge Er FF Freezer Fan Motor Fault Check evaporator coil icing, clear fan blade obstruction, replace fan motor. Book Fix
Fridge Er IF Ice Maker Fan Error Inspect ice room fan ducting, test motor resistance, replace ice blower unit. Book Fix
Fridge Er dH Defrost Heater / Thermistor Circuit Test defrost heater continuity, replace open thermal fuse or defrost thermistor. Book Fix
Dryer tE1 / tE2 Thermistor Sensor Failure Test temperature thermistor resistance, replace faulty heat sensor unit. Book Fix
Dryer d80 / d90 Exhaust Duct Blockage (80%-90%) Clean internal lint trap housing and clear wall vent ducting of restriction. Book Fix
Dishwasher AE / E1 Water Leakage Float Sensor Triggered Inspect base tray water level, locate tub or sump hose leak, replace damaged gasket. Book Fix

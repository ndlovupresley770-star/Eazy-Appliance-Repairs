Diagnostic Guide

Common Appliance Error Codes & Troubleshooting

Is your appliance flashing a digital error code or warning light? Use our quick lookup tool to identify the fault before calling our technical desk.

Brand Code Appliance Diagnosed Problem Recommended On-Site Fix Action
Samsung 4E / 4C Washing Machine / Dishwasher Water Supply Fault (No Water Intake) Inspect inlet valve, clear mesh filter, check water pressure switch. Book Fix
Samsung 5E / 5C Washing Machine Drainage Failure (Water Not Emptying) Clean drain pump filter, inspect impeller, replace failed drain pump. Book Fix
LG OE Washing Machine / Dishwasher Water Outlet / Drain Error Clear pump hose blockages, check drain motor winding, replace pump. Book Fix
LG LE Direct Drive Washer Motor Locked / Overload Error Inspect Direct Drive hall sensor, test motor coils, clear drum obstruction. Book Fix
Defy E4 Dishwasher / Washing Machine Water Overflow / Leak Detected Inspect bottom tray float switch, replace worn door seal or tub hose. Book Fix
Defy E1 Washing Machine Door Lock / Interlock Failure Inspect safety door latch switch, repair wiring loom, replace interlock. Book Fix
Bosch E15 Dishwasher Base Tray Leak Protection Triggered Clear internal sump leak, reset safety microswitch, swap worn pump seal. Book Fix
Bosch E18 / F18 Washing Machine Drain Time-Out Error Clear coin trap filter, inspect drain hose, install original EcoSilence pump. Book Fix
Whirlpool F06 / E01 Washing Machine Drive Motor Speed Sensor Fault Test motor tachometer coil, check belt tension, replace motor brushes. Book Fix

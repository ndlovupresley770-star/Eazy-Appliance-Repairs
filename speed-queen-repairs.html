Is your Speed Queen washer or dryer flashing an error code or experiencing mechanical breakdown? Use our instant lookup tool to identify the issue and recommended technician fix.

Top Loader uB / E-uB Unbalanced Wash Load Detected Inspect tub centering springs, check fluid balance ring, recalibrate outer tub suspension. Book Fix

Front Loader Er, nL No Water Fill / Drain Timeout Fault Clear coin trap obstruction, inspect water inlet valve solenoids, test commercial drain pump motor. Book Fix
Front Loader Er, PF Power Failure / Grid Surge Lockout Reset main circuit breaker, test microprocessor voltage regulator, clear fault memory on PCB. Book Fix
Front Loader Loud Grinding Failed Main Tub Bearing & Water Seal Disassemble outer tub, install factory shaft seal and heavy-duty commercial bearings. Book Fix

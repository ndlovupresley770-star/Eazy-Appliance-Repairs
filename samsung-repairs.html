Samsung Appliance Error Code Diagnostic Guide

Is your Samsung appliance flashing a fault code on its digital display? Use our instant lookup tool to identify the issue and recommended fix.

Appliance Error Code Diagnosed Issue Recommended Technician Fix Action
Washer 4E / 4C Water Supply Fault (No Water Intake) Clean intake mesh filters, test solenoid valve, inspect water pressure switch. Book Fix
Washer 5E / 5C Drainage Error (Water Not Emptying) Inspect drain hose for kinks, clear coin trap, replace broken drain pump motor. Book Fix
Washer UE / UB Unbalanced Load Error Level unit legs, check shock absorbers, inspect drum suspension springs. Book Fix
Washer dE / dE1 Door Lock / Interlock Failure Inspect door latch sensor, replace burned electronic door lock assembly. Book Fix
Fridge 22E / 22C Evaporator Fan Motor Fault Test fan blade rotation, clear internal ice buildup, replace fan motor assembly. Book Fix
Fridge 25E Freezer Defrost Sensor Error Test thermistor resistance, replace failed defrost sensor or heating element. Book Fix
Fridge 88 88 Communication / Power Board Reset Diagnose main PCB control board, check power surge damage, reset control panel. Book Fix
Dryer FE Power Supply Frequency Fault Test power outlet voltage, calibrate control board frequency sensor. Book Fix
Dryer HC / HC2 Heater Overheating Protection Clear lint duct blockage, replace tripped thermal cut-off thermistor. Book Fix
Dishwasher LE / LC Water Leakage Sensor Triggered Locate internal tub leak, replace worn sump gasket or cracked water hose. Book Fix

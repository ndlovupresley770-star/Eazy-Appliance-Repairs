Bosch Appliance Error Code Diagnostic Guide

Is your Bosch Series 2, 4, 6, or 8 appliance flashing a fault code or error light? Use our instant lookup tool to identify the issue and recommended technician fix.

Appliance Error Code Diagnosed Issue Recommended Technician Fix Action
Dishwasher E15 AquaStop Safety Float Switch Activated (Base Leak) Drain base pan water, inspect sump gasket and hose connections, replace leaking seal. Book Fix
Dishwasher E09 Heating Element / Heat Pump Circuit Fault Test heat pump heater winding resistance, swap failed integrated heat pump assembly. Book Fix
Dishwasher E22 / E24 Drainage Obstruction / Impeller Blockage Clear food debris from sump filter, inspect non-return valve, test drain pump motor. Book Fix
Dishwasher E14 Water Inlet Flow Meter Sensor Fault Inspect water inlet valve filter screen, test reed switch flow sensor, replace flow meter. Book Fix
Washer E18 / F18 Drain Pump Obstruction / Timeout Clear coin trap filter, check drain hose for kinks, replace worn EcoSilence drain pump. Book Fix
Washer E16 / F16 Door Interlock Lock Mechanism Fault Check door catch alignment, test electronic door lock solenoid, replace latch unit. Book Fix
Washer E23 / F23 AquaStop Leak Sensor Triggered Inspect tub seal and inlet hose connections, dry base float, replace defective hose. Book Fix
Washer E29 Water Supply Inlet Timeout Check home water pressure, clean inlet valve mesh filter, replace solenoid valve. Book Fix
Fridge E01 / E02 NTC Temperature Sensor Circuit Error Test thermistor resistance, inspect wire harness continuity, swap faulty temperature sensor. Book Fix
Dryer E56 Condenser Airflow Restriction / Filter Full Flush heat pump condenser, clean lint filter ducting, calibrate airflow sensor. Book Fix

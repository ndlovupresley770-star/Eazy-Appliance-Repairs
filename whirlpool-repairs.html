Whirlpool Appliance Error Code Diagnostic Guide

Is your Whirlpool appliance flashing a fault code or error light? Use our instant lookup tool to identify the issue and recommended technician fix.

Appliance Error Code Diagnosed Issue Recommended Technician Fix Action
Washer F06 Motor Tachometer / Speed Sensor Fault Check motor wiring harness, inspect carbon brushes, test tachometer signal. Book Fix
Washer F08 / F12 Water Heating Element Circuit Fault Test heating element resistance, replace failed NTC thermistor or relay board. Book Fix
Washer F05 Water Temperature Sensor Error Test thermistor sensor, verify control board connection, replace faulty sensor. Book Fix
Washer F13 Door Lock Circuit Malfunction Inspect door interlock switch, test door lock solenoid, replace latch assembly. Book Fix
Fridge F1 / F2 Freezer / Refrigerator Thermistor Fault Test sensor resistance, check wire harness continuity, replace temperature probe. Book Fix
Fridge F5 Damper Control Circuit Failure Clear ice obstruction in air damper, test damper motor, replace air control unit. Book Fix
Dryer F01 / F02 Electronic Control Board / Relay Fault Test main PCB power supply, reset control module, replace faulty relay board. Book Fix
Dishwasher F6 / E4 Water Inlet / Flow Meter Fault Clean inlet valve mesh filter, check water pressure, replace flow meter assembly. Book Fix
Dishwasher F8 / E1 Drainage / Filter Obstruction Error Clear food debris from sump filter, inspect drain hose, replace drain pump motor. Book Fix
Dishwasher F2 Water Leakage Float Switch Activated Inspect tub and sump hose for leaks, dry base pan float switch, replace gasket. Book Fix
